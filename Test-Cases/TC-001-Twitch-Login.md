# Test Case TC-001

**Short Summary:** Verify successful login to Twitch with valid credentials

**Module:** Login

**Environment:** Google Chrome, Windows 11

**Preconditions:**
- User has a registered Twitch account.
- User is not logged in.

**Test Steps:**
1. Open the Twitch login page.
2. Enter a valid username or email.
3. Enter a valid password.
4. Click the **Log In** button.

**Expected Result:**
User is successfully logged in and redirected to the Twitch home page.

**Actual Result:**
User was successfully logged in and redirected to the Twitch home page.

**Status:** Pass
