**Test Case ID:** TC-006

**Short Summary:** Verify successful order placement using Credit Card payment.

**Environment:** Google Chrome, Windows 11

**Preconditions:** User has added the 14.1-inch Laptop to the Shopping Cart.

**Steps:**
1. Open the Shopping Cart.
2. Click Checkout.
3. Select Credit Card as the payment method.
4. Enter valid test payment information.
5. Click Continue.
6. Review the Confirm Order page.
7. Click Confirm.


**Expected Result:** The order is successfully processed, an order confirmation message is displayed, and the order is assigned an order number.

**Actual Result:** The order was successfully processed. The confirmation message "Your order has been successfully processed!" was displayed.

**Status:** Pass
